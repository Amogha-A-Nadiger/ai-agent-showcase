# PRD — AI Coding Agent Showcase

## Product Vision
A single-page, fun and playful landing page that proves to a non-technical person that AI coding agents can build real things. "Directed by Amogha."

## Target Users
Non-technical friends/family who have heard about AI but don't know what coding agents can actually do.

## Features (must-have)
1. Hero with bold playful headline proving AI built the page
2. "What just happened?" — plain-English explanation of AI coding agents
3. Proof gallery — 4 cards showing things AI agents built (website, game, app, animation)
4. "How it works" — 3-step visual (describe → build → review)
5. "What AI can't do (yet)" — honest section
6. "Directed by Amogha" badge at top
7. Footer with "Built by an AI coding agent" badge

## Out of scope
- No CTA, no demo widget, no featured project, no contact form

## Design
- Mood: warm, confident, surprising (fun & playful)
- Palette: cream bg #F7F3EC, ink #1A1612, accent burnt orange #D94F1E
- Fonts: Space Grotesk (headings), Inter (body), Fraunces (display/serif)
- Layout: editorial asymmetry, bento grid, oversized hero type
- Responsive: mobile-first, 375px minimum

## Non-functional
- Single self-contained index.html
- Total page weight < 500KB
- No frameworks, vanilla HTML/CSS/JS
- GitHub Pages hosted, permanent URL
